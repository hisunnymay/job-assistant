**核心工作**

- **业务流程与权限设计**：梳理法务审核、代理签字人启停等关键环节，设计 POA 申请、审批、使用及管理流程，明确业务规则、权限边界和异常场景。
- **数据建模与历史迁移**：分析 100+ 份历史 POA 文件，抽象授权人、代理签字人、授权范围和有效期等核心字段；编写 Python 脚本完成历史数据清洗、转换和线上导入。
- **方案验证与敏捷落地**：使用 Cursor 搭建多套可交互原型，通过目标用户测试验证方案并确定设计方向；完成 PRD，协同研发、测试推动系统上线和持续迭代。
- **LLM 解析流程搭建**：基于 Dify 搭建「文件上传 → OCR → LLM 信息提取 → 授权信息匹配 → 结果输出」的文档解析 Workflow。
- **信息抽取与异常机制设计**：设计授权人、代理签字人、授权范围和有效期等字段的结构化输出，并保留提取结果与原文以支持人工核验；针对 OCR 失败、无有效输出及匹配失败设计异常处理机制。
- **Prompt 优化与效果迭代**：与业务开展三轮数据标注，结合文件质量和字段差异持续优化 Prompt 与解析流程，探索 LLM 在企业文档解析场景中的能力边界。
